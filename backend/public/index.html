    How do I get a key?
    1. Go to console.groq.com and sign up or log in. It's free.
    2. Open the API Keys page and tap Create API Key.
    3. Give it any name (like “agent1102”) and tap Submit.
    4. Copy the key right away. It starts with gsk_ and Groq only shows it once.
    5. Paste it into the box above and tap Save key.

    Your key is stored encrypted and is only used for your own requests. Remove it any time to go back to the shared key.
